# 🐱 Kaybolan Kedi Simülatörü

## Dünyanın En Absürt, En Gereksiz ve En Önemli Projesi

Bu repository, insanlığın en büyük gizemini çözmek için yaratıldı: **Kedi nerede?**

Cevap: Hiçbir yerde. Çünkü bu simülasyonda kedi **asla** bulunamaz. Sonsuz döngüde kaybolur ve sen de onunla birlikte kaybolursun.

### Nasıl Çalışır?

```bash
python kedi_arayici.py
```

Program rastgele yerlerde kedi arar, rastgele süre bekler, mırıldanır ve sonunda "bulunamadı" der. Gerçek hayattaki gibi.

### Özellikler

- %100 gerçekçi kedi kaybolma deneyimi
- Sonsuz tekrar edilebilir (sonuç her zaman aynı)
- Hiçbir bağımlılık gerektirmez (sadece zaman)
- Kedi asla bulunamaz (garanti)
- Özgürlük de bazen böyle kaybolur ama onu gizli tutuyoruz

### Uyarı

Bu programı çalıştırmak kedi kaybına neden olabilir. Sorumluluk kabul etmiyoruz.
